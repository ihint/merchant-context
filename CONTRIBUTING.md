# Contributing

Open an issue before a large change.

For a checklist or protocol change:

1. Link to the primary source.
2. State which layer it affects.
3. Separate live support from planned support.
4. Add or update an example when the data shape changes.
5. Run `python3 scripts/validate.py`.

Do not add vendor claims, adoption numbers, or protocol support without a source and a check date.

By submitting a pull request, you agree that your contribution uses the repository license.
